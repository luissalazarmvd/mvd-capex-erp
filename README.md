# MVD ERP

Frontend Next.js del ERP de Minera Veta Dorada (CAPEX, Planta, Refinería, Trazabilidad, Compliance, Logística, Flota, Sostenibilidad, Activos Fijos, Kardex TRJ y TI).

- Reglas, arquitectura y contratos: [`AGENTS.md`](AGENTS.md).
- Mapa de rutas y componentes: [`docs/REPOSITORY_MAP.md`](docs/REPOSITORY_MAP.md).
- Desarrollo: `npm run dev`. Verificación: `npx eslint <archivos>` y `npm run build`.
- Despliegue: push a `main` publica en Vercel.
